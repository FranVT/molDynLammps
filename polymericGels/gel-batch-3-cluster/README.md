# README

# Descripcion de archicos
- log.lammps: Log de la simulación
- parameters.sh: Parametros del sistema
- runSim.sh: Ejecuta la simulación
- utils.sh: Archivo con funciones auxiliares
- analysis: Directorio para analizar los resultados
- data: Directorio para almacenar los resultados
- src_lmp: Scripts para las simualciones de dinámica molecular

# Objetivos/Justificación de este directorio

Se modifica la forma de declarar simulaciones.

## Objetivos
- Simplificar el proceso de declaracion de variables
- Simplificar el almacenamiento de resultados experimentales
